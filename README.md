# Spotify UI Clone

Projeto desenvolvido com **React Native + Expo** que reproduz a interface do Spotify e inclui um mecanismo de busca por **músicas** e **artistas** utilizando a **API da Last.fm**.

## Sobre

Este app foi criado para praticar desenvolvimento mobile com foco em:

- construção de interfaces inspiradas em produtos reais;
- organização de componentes reutilizáveis;
- integração com API externa para busca de conteúdo musical.

## Funcionalidades

- Clone da UI do Spotify em diferentes telas;
- Busca de músicas e artistas;
- Exibição de resultados consumidos da API do Last.fm;
- Estrutura modular com componentes reutilizáveis.
